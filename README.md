# Reyes Computer Website 💻

Bienvenido al repositorio oficial del portal web **Reyes Computer**. Este proyecto está diseñado para presentar la oferta de servicios informáticos, soluciones de infraestructura tecnológica, redes y comercialización de equipos de cómputo.

---

## 📋 Descripción General

**Reyes Computer** es una plataforma web profesional orientada a brindar visibilidad a servicios tecnológicos especializados, incluyendo:
- **Servicios Informáticos & Soporte Técnico:** Diagnóstico, mantenimiento preventivo/correctivo y optimización de sistemas.
- **Instalación de Redes:** Diseño, despliegue y certificación de redes locales (LAN), enlaces inalámbricos (Wi-Fi) y cableado estructurado.
- **Venta de Equipos:** Catálogo de soluciones en hardware, laptops, equipos de escritorio y accesorios informáticos.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5 & CSS3:** Estructura semántica y diseño adaptativo (Responsive Design).
* **JavaScript (ES6+):** Interactividad y dinámicas en el cliente.
* **Git & GitHub:** Control de versiones y alojamiento de código fuente.
